Why density −2 and not the Material default. The event volume of a run is not measured — the README says so plainly, and the follower batches at 500 rows per read for exactly that reason. A default-density table showing forty rows on a 1080p screen would make a real run unreadable. Compact is the working case here, not an option.

Why tabular figures everywhere. Durations and task numbers are scanned down a column, not read in a sentence. Proportional digits make a column of numbers ragged, and a ragged column defeats the scan.
