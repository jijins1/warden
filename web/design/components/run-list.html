"Load more", not page numbers. The endpoint paginates by keyset: it returns an opaque cursor, and there is no total and no page count to compute one from. A MatPaginator showing "page 3 of 47" would be inventing both numbers. The cursor model is also what keeps the list stable while runs are being created underneath it.

Changed is a first-class column, right-aligned with tabular figures so it can be scanned down, and zero is greyed so a non-zero value catches the eye. It is the column changed_min filters on.
